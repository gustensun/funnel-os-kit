title: AI agents and vibe coding
---
AI is only as good as the context you give it. Write down your offers, audience, voice and frameworks once, and give them to every tool you use.

## Your first agent
Pick a task you repeat every week that follows the same steps, like lead follow-up, research or turning a video into posts. Write the steps down first. Then give the agent five things: a role, the context it needs, the steps, the rules it must follow and the format of the output. Keep a human approval step before anything gets sent, published or paid.

## A good agent prompt
- Role: who the agent is and who it works for.
- Context: the business, the offer, the audience and examples of good work.
- Steps: the method, in order.
- Rules: what it must never do, like inventing numbers or sending messages on its own.
- Output: the exact format you want back.

## Scoping a vibe coding build
Write a one page brief before you build: who it is for, the one job it does, the inputs, the outputs, the screens, the data it stores and the services it connects to. Build the smallest version that does the one job, put it in front of real users, then add features.

## Security basics for AI built apps
- API keys stay on the server and in environment variables. Never put them in browser code or in the repo.
- Turn on row level security for every database table.
- Check who is signed in on every request that reads or changes data.
- Rate limit anything that costs money per call.
- Read the code that handles payments and passwords yourself, or have someone review it.

## Designing funnels with AI
Do the thinking first, then let AI build. Give it the client context, the brand bullets, the offer outline and the funnel strategy, then the copy, then the design direction: reference sites, fonts, palette and mood. Build and review one section at a time. Your job is taste and conversion judgment.

## Selling AI builds
Sell the outcome the build creates, like more booked calls or hours saved each week. Show a working demo built for their business before the call, and price it as a project with an optional monthly plan for hosting and changes.
